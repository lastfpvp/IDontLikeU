> [!NOTE]
> You'll need to build [Vencord](https://github.com/Vendicated/Vencord) first.

## Install
1. Create `userplugins` folder inside your vencord source (probably `Vencord/src`, ignore this step if you have one)
2. Run these commands:
```bash
cd userplugins
git clone https://github.com/neroki194/idontlikeu
pnpm build
```
3. Launch your Discord and head up to Settings > Plugins > Filters > Show UserPlugins, and enable the plugin.
